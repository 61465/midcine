**آخر تحديث:** 2026-07-02
**الرابط الحيّ:** http://localhost:3000
**الجمهور:** مدير المشفى · رئيس قسم الأشعة · CIO

---

## القيمة في جملة واحدة
midcine يختصر زمن تقرير الأشعة من **20 دقيقة إلى 10** ويرصد الحالات الحرجة قبل تفويتها، عبر أنسمبل ٤ نماذج AI عربية أصلية، مع بقاء البيانات داخل المشفى.

## 🔬 30-Minute Deep-Dive (يضيف على السابق)

| دقيقة | موضوع | مفاتيح النقاش |
|---|---|---|
| 15-18 | البنية التقنية | Next.js 15 + React 19 + FastAPI + Postgres/paradedb + Redis Streams + Orthanc PACS |
| 18-21 | NEXUS Ensemble | `services/mcp-bridge/app/atlas_matcher.py` — كل حالة لها keywords · قابل للتوسّع بلا كود |
| 21-24 | Edge-First Security | ADR-009: DICOM لا يغادر المشفى · فقط hash + consent للسحاب |
| 24-26 | تكامل EMR | HL7 v2 + FHIR R4 (ImagingStudy + DiagnosticReport) · مستشفى الجامعة sample |
| 26-28 | التسعير | Solo/Center/Enterprise · Pilot ٣ شهور مجاناً |
| 28-30 | الخطوات التالية | التوقيع · جدول التنفيذ · فريق الدعم |

## Objections القصيرة (تفصيل في OBJECTIONS.md)

| اعتراض | جواب سريع |
|---|---|
| "لدينا PACS" | midcine مكمّل لا بديل · يقرأ من Orthanc/DICOM موجود |
| "AI لا يُعتمد عليه" | AI يقترح · الطبيب يوقّع · consensus < 75% = مراجعة إلزامية |
| "دعم عربي ضعيف" | RTL أصلي · تقارير عربية كاملة · لا ترجمة |
| "امتثال" | HIPAA + PDPL + سدايا + EDA · dossier جاهز |
| "انترنت مقطوع" | edge box محلي · sync عند العودة |
| "الأطباء لن يتقبّلوه" | ٢ ساعة تدريب · واجهة مألوفة · Pilot ٣ شهور مجاناً |
| "التكامل يستغرق سنة" | DICOM ١-٢ يوم · HL7 أسبوع · FHIR جاهز |
| "مقارنة بـ Aidoc/Rad AI" | edge-first · ensemble ٤ نماذج · عربي · نصف السعر |
