## What's new since 2026-07-14

### Viewer
- **Pro DICOM Viewer (NiiVue) — fully working on every modality:**
  - Fixed `Image type not supported` — NIfTI URL now clean (`.nii.gz`) with series UID in HTTP header
  - **Auto-window contrast** — computes 1st/99th percentile from actual voxel data; works when DICOM WindowCenter/Width missing or wrong (MRI T1_TSE, T2, DWI, etc.)
  - **Adaptive slice-count handling** — any study from 20 to 800+ slices
- **Slice navigation UI:**
  - Prev/Next buttons + slider with amber markers on AI-finding positions
  - Real-time `N / total` counter synced to NiiVue's crosshair
  - "Next finding" quick-jump button
- **AI warning banner (per slice):**
  - Auto-appears when current slice is inside an AI finding range
  - STAT (red) / URGENT (orange) / INFO (amber) priority badges
  - Location + confidence % surfaced

### AI reliability
- **Adaptive batch sizing** — vision analysis auto-tunes based on slice count:
  - ≤24 slices: batch=8, tile=384px, parallel=4 (max quality)
  - 25-60: batch=12, tile=320px, parallel=4
  - 61-120: batch=16, tile=288px, parallel=4
  - 121-250: batch=20, tile=256px, parallel=3 (e.g. 156-slice MRI)
  - >250: batch=32, tile=224px, parallel=3
- **Retry with exponential backoff** — 3 attempts per batch (2.5s / 5s / 10s)
- **Session-scoped provider blacklist** — daily-quota-exhausted providers (Groq TPD) skipped for the rest of the process; no more 30s waste per batch
- **Removed dead providers** — `naraya-llama4` + `naraya-llama4-alias` (both 404'd every call)
- **Retry-After honored** — per-minute 429 waits before fallback
- **Staggered launches** — 0.3s spacing to avoid burst rate-limits

### Progress bar
- New endpoint `GET /ai/vision-see-full/progress/{job_id}`
- Client generates UUID, polls every 1.5s during long analyze
- Button shows `Analyzing… 3/10 batches · 45s` + gradient progress bar

### Anti-hallucination (2026-07-19)
- **`VISION_MULTIMODAL_SYSTEM`** — absolute rule: "You are FORBIDDEN from inventing, inferring, or filling in any finding not directly visible"
- **`FINAL_REPORT_COMPOSER_SYSTEM`** — 6 anti-hallucination rules:
  1. Findings ONLY from AI JSON + supplied documents
  2. Coverage honesty — mandatory verbatim line when < 100%
  3. No speculation ('suggestive of' only if in source)
  4. No inferred measurements
  5. No symptom-driven findings
  6. Identity verbatim character-for-character
- **Coverage block** — composer receives explicit UNREAD slice ranges from failed batches
- **Recommendations #1 auto-enforced** when coverage < 100% → "Direct radiologist review of unread slices"

- `/legal` page (22 KB, 8 sections)

## Known limitations

- Viewer requires **≥2 slices with ImageOrientationPatient/PositionPatient** — 2D X-rays (CR/DX/DR/MG) not yet supported
- Public URL has **no authentication** — anyone with the link can read/write. Add auth before wider distribution.
- Tailscale Funnel = **not HIPAA-compliant** for real patient data at scale
- Vision quality depends on free-tier Groq / Naraya availability — daily quota exhaustion possible
